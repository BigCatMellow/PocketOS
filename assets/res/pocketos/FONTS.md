# Included fonts

PocketOS includes these bundled display fonts for its font picker:

- DejaVu Sans Bold — Bitstream Vera / DejaVu Fonts license
- Lato Bold — SIL Open Font License 1.1
- Noto Sans Bold — SIL Open Font License 1.1
- Roboto Condensed Bold — Apache License 2.0

All four were selected for clear, sturdy rendering at the small text sizes used by PocketOS.
